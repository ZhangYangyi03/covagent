boundary: expose it as `covagent boundary`, with its own exit code

    python -m covagent boundary --dump obj/cov.dat \
        --seam-json bench/seam/seam.json --info coverage.info

Exit 2 when a seam is bound to the wrong driver, 0 when every seam crossed, and
1 -- not 2 -- when the input is a converted report rather than a raw database.
The distinction is the point: "the wiring is wrong" and "I was not given the data
to say" are different answers and should not share a return code.

--dump is a covagent dump, obj/cov.dat or `verilator_coverage --write` output;
coverage.info is accepted only for the line-coverage line at the top of the
report, which is there to show what the report does and does not contain.
